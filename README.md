# Попугай наоборот: билд 2

Пятиминутный забег по ГДД. Godot 4.7.1 (обычная сборка), GDScript, вся графика и звук процедурные.

## Как открыть

1. Запустите `C:\godot\Godot_v4.7.1-stable_win64.exe`.
2. Если проекта нет в списке: «Импорт» → `C:\Pointvill\parrot_game\project.godot`.
3. Откройте проект и нажмите F5.

## Управление

| Что | Как |
|---|---|
| Лапка | движение мыши: толкает носки |
| Таран (с 0:20) | резкий рывок мышью в попугая |
| Запрет умения | когда попугай выбирает умение (кольцо карт вокруг него), за 1,5 с ткнуть ЛКМ в одну карту |
| Бросок носка | зажать ЛКМ или ПКМ на носке: он тяжёлый, лапка ползёт медленно, на бросок 2,5 с. Потянуть мышь туда, куда бросить, и отпустить (откат 3 с) |
| Подмена проса (с первого крупного колоска) | ЛКМ по колоску → капкан, тухлое, яйцо или снаряд (откат 30 с) |
| Книга с полки (с 2:00) | Q или 1 |
| Корзина белья (с 3:00) | W или 2 |
| Очередь ивентов | перетаскивать в левой полосе, пока ивент не объявлен |
| Пауза / звук / заново | Пробел / M / R |
| Ускорить ×3 / мысли ИИ | F2 / F3 |

## Что в забеге

- 5 минут, гонг орды каждые 50 с, 4 ивента (пятно солнца, светящееся просо, шкатулка-беглянка, лакомство), робот-пылесос на 4:00.
- Попугай: всегда клюёт, берёт не больше 3 умений из 5, 3 общих пассивки и по одной особой пассивке на умение (5 вариантов у каждого). Выбор показывается кругом вокруг него.
- Фрукты за ивенты и босса: герой ест их сам (яблоко, перец, морковка, виноград, лимон).

## Проверка без графики

```
C:\godot\Godot_v4.7.1-stable_win64_console.exe --headless --path C:\Pointvill\parrot_game --fixed-fps 20 -- --sim
```

`--nobot` убирает бота с книгами, `--fullbot` добавляет «сильного игрока» (броски, подмены, корзина), `--selftest` прогоняет все действия игрока без мыши.

## Журналы боёв

Каждый забег пишется в `%APPDATA%/Godot/app_userdata/Попугай наоборот/runs/run_<дата>.txt`: итог, урон по источникам, все действия игрока, мысли героя и снимок состояния раз в 10 с. Прерванный клавишей R забег тоже сохраняется.

## Сохранение

`%APPDATA%/Godot/app_userdata/Попугай наоборот/save.json`: число забегов, пройденное обучение, перья, награды из яиц и память попугая (что его било и чем он лучше бил). Удалите файл, чтобы начать «с нуля» с обучением и пустой памятью.
