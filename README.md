# Попугай наоборот: стартовый билд

Первый играбельный срез первого забега по ГДД. Godot 4.7.1 (обычная сборка), GDScript, вся графика процедурная.

## Как открыть

1. Запустите `C:\godot\Godot_v4.7.1-stable_win64.exe`.
2. В менеджере проектов нажмите «Импорт» и выберите `C:\Pointvill\parrot_game\project.godot`.
3. Откройте проект и нажмите F5 (или ▶ в правом верхнем углу).

Без редактора: `C:\godot\Godot_v4.7.1-stable_win64.exe --path C:\Pointvill\parrot_game`

## Управление

| Что | Кнопка |
|---|---|
| Кошачья лапка | движение мыши: толкает носки, тапки поддаются наполовину, Рука не поддаётся |
| Таран (с 1:30) | резкий рывок мышью в попугая: оглушение 0,5 с, лапка ушиблена 4 с |
| Книга с полки | ЛКМ или 1: тень 1,2 с, радиус 2,5 м, 15% здоровья героя |
| Корзина белья (с 3:00) | ПКМ или 2: 12 носков и 2 тапка у стены, к которой ближе лапка |
| Пауза | Пробел / Esc |
| Ускорить ×3 | F2 |
| Мысли ИИ (16 лучей, поле опасности) | F3 |
| Новый забег | R |

## Что есть

- Комната с мебелью, стены и препятствия для всех.
- Орда: носки (прыгают), звенящие шарики (рой со «дзынь» заранее), тапки, пульверизаторы, Рука с кормушкой (хват с предупреждением 0,5 с). Гонг каждые 2 минуты усиливает орду.
- Попугай Кеша с ИИ из части 2 ГДД: 3 слота внимания (рамки на экране), поля опасности и интереса, режимы фарм / к цели / охота / отход / паника, вальс вокруг орды, туннель жадности, инерция страха, замечает тень книги за 0,25 с в фокусе и за 0,7 с вне его.
- Левелап без паузы: время замедляется до 30% на 1,5 с, видно три карты, оценки героя и его колебания; выбор учитывает план (Колокольчик + Пух) и то, чем его били последние 2 минуты.
- Интерфейс: шкалы здоровья, стресса и жадности, цели героя, лента мыслей, перетягивание «мощь героя ↔ мощь орды», «Загон», «На волоске», «СОРВАНО», итог забега.

## Баланс без графики

```
C:\godot\Godot_v4.7.1-stable_win64_console.exe --headless --path C:\Pointvill\parrot_game --fixed-fps 20 -- --sim
```

`--sim` гоняет 30 минут за ~20 секунд с ботом, который кидает книгу с упреждением при каждом откате; `--nobot` убирает бота. Сейчас: без игрока герой живёт 20–27 минут, с ботом попадает примерно каждая пятая книга.

Ручки баланса: `scripts/main.gd` (константы вверху, `EDEFS`, `_director`), `scripts/hero.gd` (характер, веса внимания и страха), `scripts/perks.gd` (тиры и ответы на урон).
