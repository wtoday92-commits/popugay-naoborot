# Попугай наоборот: билд 2

Пятиминутный забег по ГДД. Godot 4.7.1 (обычная сборка), GDScript, вся графика и звук процедурные.

## Как открыть

1. Запустите `C:\godot\Godot_v4.7.1-stable_win64.exe`.
2. Если проекта нет в списке: «Импорт» → `C:\Pointvill\parrot_game\project.godot`.
3. Откройте проект и нажмите F5.

## Управление

| Что | Как |
|---|---|
| Рогатка | зажать ЛКМ/ПКМ на носке или тапке, оттянуть лапку назад и отпустить. Носок издалека разгорается и бьёт сильнее, тапок выбивает фрукты. Откат 3 с |
| Таран | резкий рывок мышью в попугая |
| Исследования (открываются за перья между забегами) | подмена проса (ЛКМ по колоску), книга [Q], корзина-ловушка [W], запрет умения, 3-й и 4-й ивенты |
| Очередь ивентов | перетаскивать в левой полосе, пока ивент не объявлен |
| Пауза / звук / заново | Пробел / M / R |
| Ускорить ×3 / мысли ИИ | F2 / F3 |

## Забег

- Попугай выбирается из комнаты, только сломав робота-пылесоса (4:00, ярость на 6:00). Комната каждый раз другая, без узких проходов.
- Со старта 2 ивента до босса; ещё два открываются исследованиями.
- После забега: экран попугая (просо, прокачка, достижения, выбор 2 квестов из 6) и экран игрока (исследования за перья).

## Проверка без графики

```
python tools/balance.py nobot 16      # без игрока
python tools/balance.py mid 16        # средний игрок: рогатка и таран
python tools/progression.py 12 6      # 6 серий по 12 забегов с обучением и метой
```

Итоги последних прогонов — в `docs/balance_report.md`. Флаги одиночного запуска: `-- --sim --nobot`, `--midbot`, `--fullbot`, `--prog`, `--learn`, `--selftest`.

## Журналы и сохранение

Журналы боёв: `%APPDATA%/Godot/app_userdata/Попугай наоборот/runs/`. Сохранение (забеги, перья, исследования, прокачка и память попугая): `save.json` в той же папке. Удалите его, чтобы начать с нуля.
